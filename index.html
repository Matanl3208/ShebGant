OneDrive Sync

Share this chart's data with teammates via a OneDrive file
This needs a one-time setup (per organization, not per person):
  1. Create a free Azure AD App at portal.azure.com → App registrations → New registration (type: SPA, redirect URI = the https address this file is hosted at).
  2. Add API permission Files.ReadWrite (Microsoft Graph, delegated).
  3. Create (or ask someone to create) one JSON file on OneDrive to act as the shared data file, and share it with "Can edit" to your teammates.
This file must be opened from an https:// address (not double-clicked locally) for Microsoft sign-in to work.
Not connected — edits are only saved to this chart.
